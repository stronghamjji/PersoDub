      What PersoDub does

      Dubbing

      Voices a video in another language, in each speaker’s own voice. You get the dubbed video, its subtitles and a script you can fix line by line.

      This computer (10 languages, free) or Perso API (100+ languages, credits).
      Separate audio

      Splits the sound into Voice (only the speech) and Background (music, effects, noise). Save either one, or go on to Dubbing.

      This computer or Perso API.
      Erase subtitles

      Takes subtitles burned into the picture out. Box them, press Erase, and dub the clean video.

      This computer. The eraser downloads the first time.
      Save video

      Paste a YouTube, TikTok or Reels link. The video is fetched to this computer; Export saves it, or dub it, separate it or erase it from there.

      This computer.
      Dub Agent

      Ask in plain words, such as “Korean dubbing for this link” or “make line 9 fit”. It works through the same tools and shows each step.

      Claude Code, installed and signed in, or Codex, which the app can download and sign in.
